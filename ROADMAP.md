# Public Roadmap

This roadmap describes broad public priorities for Campaign Manager without exposing proprietary implementation details or making fixed delivery promises.

Campaign Manager is actively maintained as a free Community / Self-Hosted political campaign and election management platform, with optional professional services available separately.

## Current priorities

### Documentation and installation quality

- improve cPanel and VPS deployment guidance;
- expand troubleshooting material;
- keep upgrade instructions aligned with published releases;
- improve privacy-safe screenshots and product walkthroughs;
- add practical political-campaign operations guides.

### Campaign operations

- continue refining supporter/member, political-structure and field-operation workflows;
- improve clarity around campaign scopes and electoral geography;
- strengthen Polling Unit Agent operational guidance;
- improve election-day monitoring and Situation Room documentation.

### Reliability and maintainability

- continue regression testing around installation and geography provisioning;
- improve upgrade safety and release notes;
- strengthen security guidance and responsible-disclosure processes;
- continue improving performance and operational diagnostics where required.

### Community foundation

- use GitHub Issues for reproducible bugs and documentation problems;
- use GitHub Discussions for questions, ideas and campaign-technology knowledge sharing;
- welcome documentation, deployment, translation and tutorial contributions;
- publish useful educational material around self-hosted campaign technology and election operations.

## Optional service improvements

Campaign Manager may also continue improving the experience around optional services such as QuickStart Geography Provisioning, Professional Installation, Priority Support, Managed Deployment, Campaign SMS and custom integrations.

These services do not change the principle that Community / Self-Hosted Campaign Manager can be downloaded and operated independently without a software licence fee.

## How to suggest an idea

Use GitHub Discussions for early ideas and community conversation. Use the Feature Suggestion issue template when you can describe a concrete use case, problem and expected outcome.

Roadmap items may change as real deployments, user feedback, security work and election-cycle needs evolve.
