# Support

Campaign Manager has different support channels depending on what you need.

## GitHub Issues — bugs and documentation problems

Use **GitHub Issues** when you can describe a reproducible problem with the public Campaign Manager release or its documentation, for example:

- installation failures;
- reproducible application bugs;
- broken documentation links;
- unclear setup instructions;
- errors in public guides.

Before posting, remove passwords, `.env` values, tokens, database credentials, QuickStart keys, server credentials, supporter/member records, identity documents and private campaign information.

For installation problems, include the Campaign Manager version, hosting type, PHP version, database type/version, web server, installation stage, exact error message and sanitised logs where safe.

## GitHub Discussions — community questions and ideas

Use **GitHub Discussions** for questions and conversations that are not reproducible bugs, including:

- installation approaches and hosting experiences;
- campaign-operations questions;
- feature ideas;
- deployment patterns;
- tutorials and community knowledge;
- political-tech and civic-tech discussions relevant to Campaign Manager.

A Discussion is the better place when you want advice, comparison or community input rather than a defect fix.

## Professional services — paid technical assistance

Campaign Manager Community / Self-Hosted is free to download and use. You can deploy and operate it yourself without purchasing a software licence.

Campaign Manager / Govware Solutions can provide optional paid services when your team wants technical assistance or convenience, including:

- **QuickStart Geography Provisioning** — automatically installs the supported Regions, States, Senatorial Districts, Federal Constituencies, LGAs, Wards and Polling Units relevant to the campaign scope purchased, instead of requiring the campaign team to create those records manually;
- **Professional Installation** — deployment and configuration on customer-controlled infrastructure;
- **Priority Technical Support** — paid troubleshooting and technical assistance;
- **Managed Deployment** — infrastructure, deployment, monitoring, maintenance and technical operations handled for the campaign;
- **Campaign SMS** — optional managed messaging service;
- **Custom Development / Integration** — agreed campaign-specific integrations or customisation;
- **Migration / Upgrade Assistance** — help moving or upgrading an existing deployment.

Current service information is available at [campaignmanager.ng](https://www.campaignmanager.ng).

## Security reports

Do not disclose security vulnerabilities or sensitive campaign data in a public issue or discussion. Follow [SECURITY.md](SECURITY.md) for the private reporting route.

## What support contributions are not

Voluntary development support is separate from professional services. A contribution does not purchase a software licence, technical-support entitlement, political influence or preferential treatment.
