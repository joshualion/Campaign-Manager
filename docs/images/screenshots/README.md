## Privacy rules

Do not publish screenshots containing:

- identifiable All Members directory records;
- names, emails, phone numbers or addresses from agent request/nomination/assignment workflows;
- identity documents or voter evidence;
- Profile or Change Password details;
- License Status, Portal SMS Settings or SMTP secret-bearing configuration;
- real internal conversations, email content, announcements or election evidence without a fresh privacy review;
- passwords, tokens, API keys or QuickStart keys.

## Capture guidance

- Use the verified demo portal only.
- Populate meaningful privacy-safe demo data before capture where a screen would otherwise be empty.
- Remove or replace real personal information, credentials, tokens and private political data.
- Prefer a consistent browser viewport and 16:9 crop.
- Keep key UI text readable at GitHub README width.
- Use WebP for a good size/quality balance; PNG is acceptable where it preserves UI text better.
- Avoid excessive browser chrome unless it adds useful context.
