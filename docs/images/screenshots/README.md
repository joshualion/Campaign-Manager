## Capture guidance

- Use the verified demo portal only.
- Populate meaningful demo data before capture where the screen would otherwise be empty.
- Remove or replace real personal information, credentials, tokens and private political data.
- Prefer a consistent browser viewport and 16:9 crop.
- Keep key UI text readable at GitHub README width.
- Use WebP for a good size/quality balance; PNG is acceptable where it preserves UI text better.
- Avoid excessive browser chrome unless it adds useful context.
