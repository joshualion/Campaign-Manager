# Campaign Manager Licence Status

Campaign Manager Community / Self-Hosted is currently distributed as software that is **free to download and use**.

That statement does **not** automatically grant open-source redistribution, modification, sublicensing or source-code rights.

## Current repository status

At the time of this documentation update:

- the GitHub repository does not declare an SPDX/open-source licence;
- no MIT, GPL, Apache or similar open-source licence is being added by this documentation work;
- the public repository primarily provides Community documentation and official release distribution;
- the application package may be used under the current Community free-use model, but users should not assume additional IP rights that have not been expressly granted.

## Decision still required

The project owner should make an explicit licensing decision before the repository claims to be open source or grants redistribution/modification rights.

Possible high-level models include:

### 1. Proprietary / source-available-style free-use terms

The application can remain free to use while reserving redistribution, resale, modification or source rights except where expressly permitted.

**Effect:** strongest control over redistribution/commercial copying, but less attractive to contributors who expect standard open-source rights.

### 2. Permissive open-source licence (for example MIT/Apache-style)

Would broadly allow use, modification and redistribution subject to the selected licence conditions.

**Effect:** easier ecosystem adoption and reuse, but materially reduces control over redistribution and competing derivative offerings.

### 3. Copyleft open-source licence (GPL/AGPL-style)

Would grant open-source rights while imposing reciprocal source/licensing obligations on certain derivatives/distributions; AGPL can extend obligations to network use.

**Effect:** encourages an open ecosystem while protecting reciprocity, but still represents a major IP-policy decision and may affect commercial integration choices.

### 4. Dual/commercial licensing model

A project can offer one licence for Community use and separate commercial terms for other use cases, but the exact structure must be drafted carefully.

**Effect:** can balance adoption and commercial control, but requires clear legal terms and licence compatibility planning.

## Until a decision is published

Do not describe Campaign Manager as open source merely because the Community package is free.

Do not add a standard open-source licence file without explicit project-owner approval and legal/strategy review.
