# Frequently Asked Questions

## Is Campaign Manager free?

Yes. Campaign Manager Community / Self-Hosted is free to download and use on infrastructure you control.

Optional services such as QuickStart Geography Provisioning, Professional Installation, Priority Support, Managed Deployment, Campaign SMS and custom work are paid separately.

## Is a licence key required?

No software licence key is required to run the Community / Self-Hosted edition.

A **QuickStart Geography Provisioning Key** may be used if you purchase the optional QuickStart service, but that key authorises geography provisioning only. It is not a software licence key.

## Can I self-host Campaign Manager?

Yes. Self-hosting is the normal Community model. Your team provides and manages the server, database, domain, SSL, storage, backups and other operational infrastructure.

## Can I configure geography myself?

Yes. Manual Geography Configuration is free.

You can configure the geography relevant to your campaign scope yourself instead of buying QuickStart.

## What is QuickStart?

QuickStart Geography Provisioning is an optional paid convenience service that provisions supported electoral geography for the campaign scope/geography purchased through the Campaign Manager Portal.

See [QuickStart](quickstart.md).

## What campaign scopes are supported?

Supported high-level scopes are:

- Presidential / National
- Governorship / State
- Senatorial
- Federal Constituency
- Local Government / Chairmanship

See [Campaign Scopes](campaign-scopes.md).

## Can Campaign Manager manage supporters?

Yes. Supporter/member management is part of the Campaign Manager feature set, alongside political structures, field operations and campaign geography.

## Can it manage polling units?

Yes. Polling-unit management is supported within the relevant campaign geography and scope.

## Can it manage field agents?

Yes. Campaign Manager includes field/agent management workflows associated with campaign structures and polling-unit operations.

## Does it support election monitoring?

Yes. Campaign Manager includes election monitoring and election reporting/results workflows. Detailed verified screenshots and feature descriptions will be added after the current live-demo audit is completed.

## Can Govware install it for me?

Yes. Professional Installation is an optional paid one-time technical service. Govware can deploy and configure Campaign Manager on infrastructure you provide/fund.

You can still install Community Campaign Manager yourself for free.

## What is Managed Deployment?

Managed Deployment is an optional service for campaigns that want Govware to handle agreed technical operations such as deployment, infrastructure planning, monitoring, maintenance, updates and support during the campaign/election cycle.

It is separate from the free Community software.

## Is SMS included?

SMS is optional and funded separately where available. Community use does not require Campaign SMS.

See [Campaign SMS](sms.md).

## How are updates delivered?

Official application updates are published through:

[GitHub Releases](https://github.com/joshualion/Campaign-Manager/releases)

Review the release notes and back up your deployment before upgrading.

See [Upgrading](upgrading.md).

- [Installation Guide](installation.md)

- GitHub Issues for reproducible public repository/documentation/install problems that contain no sensitive data

For optional paid installation, priority support, managed deployment or custom work, use:

[www.campaignmanager.ng](https://www.campaignmanager.ng)

## Is Campaign Manager open source?

Do not assume that from the free Community download.

The repository currently has no declared open-source licence, and free-to-use does not automatically grant redistribution, modification or source-code rights. A formal licence decision is still required.
