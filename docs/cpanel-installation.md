# Installing Campaign Manager on cPanel / Shared Hosting

This guide is for technically competent users deploying the Community / Self-Hosted edition on cPanel-style hosting.

> Community use is free and does not require a software licence key. QuickStart Geography Provisioning is optional.

## Before uploading anything

Confirm your hosting account allows you to:

- choose a PHP version supported by the Campaign Manager installer;
- enable required PHP extensions reported by the installer;
- create a MySQL/MariaDB database and user;
- set a domain/subdomain document root to the application's `/public` directory;
- create/edit `.env`;
- use HTTPS;
- write to `storage/` and `bootstrap/cache/`.

If your provider prevents the document root from pointing to `/public`, ask support to adjust it or use a subdomain/addon domain whose document root can be set correctly. Avoid exposing the Laravel application root just to work around a hosting limitation.

## 1. Download the official release

Download `campaign-manager.zip` from:

[GitHub Releases](https://github.com/joshualion/Campaign-Manager/releases/latest)

Do not use GitHub's auto-generated source archive in place of the release asset.

## 2. Create an application directory

Using **File Manager**, create a directory outside `public_html` where possible, for example:

```text
/home/CPANEL_USER/apps/campaign-manager
```

Upload `campaign-manager.zip` there and extract it.

After extraction, confirm you can see Laravel directories such as `app`, `bootstrap`, `config`, `public`, `resources`, `routes` and `storage`.

## 3. Point the domain to `/public`

In cPanel's Domains/Subdomains interface, set the relevant domain's document root to:

```text
/home/CPANEL_USER/apps/campaign-manager/public
```

The web-accessible root should be the release's `public/` directory — not the application directory above it.

## 4. Select PHP

Use **MultiPHP Manager**, **Select PHP Version** or the hosting provider's equivalent.

The public repository intentionally does not guess the required PHP version/extensions because the private dependency manifest is not published here. Open the installer Requirements step after the domain is mapped and use it as the authoritative compatibility check.

If the installer reports a missing extension, enable it in cPanel or ask the provider to enable it.

## 5. Create the database

Use **MySQL Databases** or **MySQL Database Wizard**:

1. create a new database;
2. create a dedicated database user;
3. use a strong password;
4. add the user to the database;
5. grant the privileges required for the application to create/update its own schema.

Record the full cPanel-prefixed database/user names exactly as shown.

Typical values look like:

```text
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=account_campaign
DB_USERNAME=account_campaignuser
DB_PASSWORD=strong-secret
```

Your provider may use a remote database hostname instead of `localhost`.

## 6. Configure `.env`

If the installer handles environment configuration on your host, follow it. Otherwise copy `.env.example` to `.env` using File Manager or Terminal and enter the correct application/database settings.

If Terminal is available and an application key is required but not yet generated by the installer:

```bash
php artisan key:generate
```

Never expose `.env` publicly.

## 7. Permissions

Campaign Manager needs Laravel's writable directories to be writable by the application/web-server context:

```text
storage/
bootstrap/cache/
```

On normal cPanel hosting, account-owned files with the provider's recommended permissions are preferable to world-writable permissions. Do not default to `777`.

If you get permission errors, use the provider's expected ownership/permission model rather than widening permissions indiscriminately.

## 8. Enable SSL

Use **SSL/TLS Status**, AutoSSL or the provider's certificate tooling. Confirm:

```text
https://your-domain.example
```

works before production use. Set `APP_URL` to the same HTTPS URL.

## 9. Run the installer

Open:

```text
https://your-domain.example/install
```

Complete requirements, environment, database, mail/storage, campaign scope/geography, campaign identity, geography setup and Super Administrator configuration.

For geography:

- **Manual** is free and requires no key.
- **QuickStart** is optional and uses a provisioning key purchased for the selected scope/geography. The key is not a software licence.

## 10. Cron / scheduler

If an enabled Campaign Manager feature requires Laravel scheduled tasks, add a cPanel Cron Job similar to:

```text
* * * * * cd /home/CPANEL_USER/apps/campaign-manager && /usr/local/bin/php artisan schedule:run >> /dev/null 2>&1
```

The PHP binary path varies by provider; use the provider's documented CLI PHP path.

## 11. Queues

The installer may use synchronous processing during first-run setup. If you later configure an asynchronous queue connection, your hosting plan must provide a supported way to keep the worker running (for example a process manager, hosting queue service or supervised command). Do not switch queue drivers without also arranging the corresponding worker.

## Common cPanel mistakes

### Pointing the domain at the application root

**Wrong:**

```text
/home/account/apps/campaign-manager
```

**Correct:**

```text
/home/account/apps/campaign-manager/public
```

### Uploading the GitHub source ZIP instead of the release asset

Use `campaign-manager.zip` from the Releases page.

### Forgetting the cPanel username prefix

The displayed database/user name may include your cPanel account prefix. Use the exact value shown in cPanel.

### Incorrect PHP CLI version

The web PHP version and Terminal/Cron PHP binary can differ. When running Artisan from Terminal/Cron, verify the CLI PHP version as well.

### Using `777`

World-writable permissions are not a normal fix. Correct ownership/group settings instead.

### Wrong APP_URL

Use the final HTTPS URL — not localhost, a temporary cPanel preview URL or an old domain.

### Extracting inside the wrong directory

After extraction, make sure the actual Laravel `public/` directory is the domain root. Watch for accidental nesting such as:

```text
campaign-manager/campaign-manager/public
```
